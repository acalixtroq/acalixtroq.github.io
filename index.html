01. Análisis de Embudo de Ventas (E-commerce)

SQL Excel KPIs

Contexto

Simulación de un entorno E-commerce. El objetivo fue reconstruir el "Customer Journey" para identificar por qué los usuarios abandonaban el carrito de compras.

Mi Análisis

  • Unifiqué tablas de eventos y usuarios (front y back) usando JOINs y subconsultas.
  • Calculé la tasa de conversión por etapas para detectar fugas.
  • Segmenté la data por ubicación geográfica para encontrar patrones regionales.

Resultados Clave

🚨 Identifiqué una caída crítica del 85% en el "Add-to-Cart". Además, detecté un fallo técnico en Ecuador, Colombia y Paraguay (0% conversión), recomendando revisión inmediata de pasarelas de pago.

02. Análisis de Movilidad Global

Python Pandas Visualización

Contexto

Investigación estadística en 387 ciudades para correlacionar la congestión vehicular con la productividad económica (PIB).

Mi Análisis

  • Procesé datos masivos de TomTom y OECD usando Pandas.
  • Limpieza: El dataset inicial tenía 96% de nulos; apliqué normalización estadística para recuperarlo.
  • Generé visualizaciones comparativas para validar hipótesis.

Resultados Clave

🏙️ Conclusión: Bogotá requiere inversión prioritaria. Como muestra el gráfico principal, tiene niveles de congestión (~1,141 mins) similares a ciudades ricas, pero con un PIB desproporcionadamente bajo.
