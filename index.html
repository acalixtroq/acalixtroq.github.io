01. Análisis de Embudo de Ventas (E-commerce)

SQL Excel Análisis de Negocio

Contexto

Simulación de un entorno real de E-commerce (tipo MercadoLibre). El objetivo fue reconstruir el "Customer Journey" para identificar por qué los usuarios no finalizaban sus compras.

Mi Análisis

  • Unifiqué tablas dispersas de eventos y usuarios usando JOINs y subconsultas complejas.
  • Realicé un análisis de cohortes para medir la retención semanal.

Conclusiones Principales

🚨 Identifiqué una caída crítica del 85% en la etapa de "Add-to-Cart". Además, detecté que Ecuador, Colombia y Paraguay tenían 0% de conversión, señalando un fallo técnico en pagos regionales.

02. Análisis de Movilidad Global

Python Pandas Limpieza de Datos

Contexto

Investigación estadística para correlacionar la congestión vehicular con la productividad económica en 387 ciudades globales.

Mi Análisis

  • Procesé datos de tráfico (TomTom) y economía (OECD) con Pandas y Seaborn.
  • Reto técnico: El dataset inicial tenía un 96% de valores nulos; implementé estrategias de normalización para salvar el estudio.

Conclusiones Principales

🏙️ Determiné que Bogotá es la prioridad de inversión regional, con niveles críticos de congestión (~1,141 mins/año) desproporcionados a sus indicadores económicos.
